# 미션 - 로또

## ⚙️ 구현할 기능 목록
### 1. 로또 구입 금액 입력
사용자로부터 구입 금액을 입력받는다.

**입력 검증 조건**
- 앞뒤 공백 허용 (trim 적용)
- 입력 값은 숫자 하나여야 한다. 내부 공백 포함되면 예외 발생
- 숫자가 아닌 문자가 포함되면 예외 발생
- Integer 범위를 초과하면 예외 발생
- 양수가 아니면 예외 발생
- 1,000원 단위가 아니면 예외 발생

**에러 처리 규칙**
- 예외 발생 시 `IllegalArgumentException`
- 에러 메시지는 항상 `[ERROR]`로 시작
- 해당 입력부터 재입력

---

### 2. 로또 발행
- 구입 금액 기준 `1000원당 1장` 발행
- 각 로또는 중복되지 않는 6개의 숫자로 구성
- 번호 범위는 `1~45`
- 발행한 로또 번호는 오름차순 정렬 후 출력

---

### 3. 당첨 번호 입력
쉼표(,)로 구분된 6개의 숫자를 입력받는다.

**검증 조건**
- 입력 형식 예시: `1,2,3,4,5,6`
- 숫자 외 문자 포함 시 예외
- 정확히 6개 숫자가 아니면 예외
- 각 번호는 `1~45` 범위
- 번호 중복 불가
- 앞뒤 공백 허용 / 요소 사이 공백 불가 (`1, 2`는 오류)

**에러 처리 규칙**
- `IllegalArgumentException`
- `[ERROR]`로 시작
- 해당 입력부터 재입력

---

### 4. 보너스 번호 입력
한 개의 숫자를 입력받는다.

**검증 조건**
- 숫자 외 문자 포함 시 예외
- 정확히 숫자 하나여야 함
- 범위: `1~45`
- 당첨 번호와 중복 불가
- 앞뒤 공백 허용

**에러 처리 규칙**
- `IllegalArgumentException`
- `[ERROR]`로 시작
- 해당 입력부터 재입력

---

### 5. 당첨 결과 계산
각 로또와 당첨 번호를 비교하여 등수 계산한다.

| 등수 | 조건 | 상금 |
|---|---|---|
| 1등 | 6개 번호 일치 | 2,000,000,000 |
| 2등 | 5개 번호 + 보너스 일치 | 30,000,000 |
| 3등 | 5개 번호 일치 | 1,500,000 |
| 4등 | 4개 번호 일치 | 50,000 |
| 5등 | 3개 번호 일치 | 5,000 |

---

### 6. 수익률 계산 및 출력
- 수익률 = `(총 수익금 / 구입 금액) * 100`
- 소수점 둘째 자리에서 반올림하여 첫째 자리까지 표시  
  (예: `62.5%`, `100.0%`)

---

## 📝 커밋 메시지 컨벤션

프로젝트의 커밋 메시지는 다음 형식을 따릅니다.

```
<type>(<scope>): <subject>
```

### Type

| Type | Description |
| :--- | :--- |
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `docs` | 문서 수정 (README.md 등) |
| `style` | 코드 포맷팅, 세미콜론 누락, 공백 등 (기능 변경 없음) |
| `refactor` | 코드 리팩토링 (기능 변경 없음) |
| `test` | 테스트 코드 추가 또는 수정 |
| `chore` | 빌드, 패키지 매니저 설정 등 유지보수 작업 |

---

## 💨 설계 원칙

- MVC 패턴 적용
- TDD 기반 개발 (기능 단위 테스트 선 작성)
- UI 로직(System.in/out) 제외한 영역에 단위 테스트 작성
- 기능 단위 커밋 및 AngularJS Git Commit 규칙 적용
- 메서드 단일 책임 원칙 준수
- 메서드 길이는 15줄 이하 유지
- 들여쓰기 depth 2 이하
- else 예약어 사용 금지
- switch-case 사용 금지
- 조건 분기는 반환 방식 활용
- Java Enum 활용 (등수/상금 등)
